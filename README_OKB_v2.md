# Тренажёр по ОКБ — версия 2

В комплекте:

- `okb_exam_trainer_v2.html` — автономный сайт-тренажёр, работает офлайн в браузере.
- `okb_knowledge_base_v2.json` — база вопросов, ответов, вариантов и источников.
- `README_OKB_v2.md` — описание комплекта.

## Что изменено во второй версии

- Добавлены все уверенно извлечённые с фото вопросы с вариантами ответа: **49**.
- База содержит всего вопросов: **141**.
- Добавлены типы заданий: один ответ, несколько ответов, ввод термина, последовательность, соответствие.
- Сайт адаптирован под телефон и компьютер: крупные кнопки, резиновая сетка, мобильная верстка, touch-friendly элементы.
- Есть фильтр «только вопросы с фото».
- Есть режим повторения сложных вопросов: ошибки сохраняются в LocalStorage браузера.

## Важно про достоверность

Учебники не были загружены полным текстом, поэтому ответы проверялись по открытым нормативным и экспертным источникам, указанным в JSON.

Если вы нашли ответ без цитаты из учебника — это баг. Сообщите, удалим.
